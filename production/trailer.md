# note_to_self — 60s Proof Trailer (HeyGen)

**Tool target:** HeyGen (scene length <= 8s)
**Total target runtime:** ~60s
**Format:** 16:9, 24fps feel, cinematic anime style
**Rule:** Keep Ada visually consistent in every scene (same character reference)

---

## Global Style Lock (use in every scene prompt)

Makoto Shinkai-inspired anime film style, hand-drawn 2D look, NOT live-action, NOT photoreal. Ada: 17-year-old girl, light olive skin, dark brown hair tied back, gray hoodie, subtle tired eyes. Melancholic, intimate, dreamlike. Blue server LED glow + warm amber practical lights. Soft film grain. Quiet camera motion.

**Negative prompt (every scene):**
live action, photoreal, ad style, corporate commercial look, glossy skin, 3D CGI doll face, UI overlays, subtitles burned in, watermark
