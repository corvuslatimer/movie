# Scene 01 — Server Room / Morning

## Purpose
Inciting anomaly. Establishes Ada's world as procedural, controlled, and emotionally muted before the first fracture appears.

## Target Runtime
~1m45s–2m15s

---

## Story Beat (What happens)
Ada performs routine morning checks in a server room. At Terminal 4, she finds an open file she did not open: `note_to_self_003.txt`.
She reads two lines that feel too intentional to be random.
She classifies it as a non-critical artifact and logs a cleanup ticket.
As she leaves, the cursor on Terminal 4 resumes blinking by itself.

---

## Setting & Environment
**Location:** Mid-size enterprise server room, not futuristic. Real-world infrastructure.

**Architecture:**
- 2 long aisles of black server racks
- cold aisle / hot aisle layout
- overhead cable trays
- raised floor panels (optional) or polished concrete

**Mood of space:**
- functional, indifferent, impersonal
- no cinematic fog, no sci-fi glow gimmicks
- this room should feel like it has no idea a tragedy is beginning

---

## Visual Design
**Color palette:**
- dominant: cold blue, charcoal, desaturated steel
- accent: tiny status LEDs (green/amber)
- skin tones slightly drained by fluorescent light

**Lighting:**
- practical overhead fluorescents only
- monitor glow for face detail at terminal
- no dramatic key light

**Lens strategy:**
- opening wide: 24mm/28mm for spatial isolation
- procedural inserts: 50mm for hands/tablet/rack labels
- terminal moment: 85mm or tighter for file text + eye movement

**Camera movement:**
- mostly locked or very slow controlled dolly
- motion should mirror Ada's routine precision
- first subtle unease begins only when she sees the file

---

## Set Dressing / Objects (must-have)
- clipboard or rugged tablet with checklist
- badge lanyard
- microfiber cloth tucked in back pocket (detail of routine care)
- label stickers on racks (R1, R2...)
- terminal keyboard with slight wear on common keys
- coffee cup ring stain near terminal base (old, not fresh)
- wall clock visible in at least one frame
- maintenance ticket interface open on one monitor

**Terminal file details:**
- filename exactly: `note_to_self_003.txt`
- monospace font, white on black
- text appears human-paced, not instant animation

---

## Sound Design
**Base layer:**
- continuous server fan bed (low-mid frequency)
- occasional relay click / airflow variance

**Foreground moments:**
- Ada's footsteps on concrete
- keyboard taps when ticket is logged
- tiny terminal beep (optional, very subtle)

**Music:**
- none

**Important:**
When Ada reads the lines, reduce ambient by ~10–15% for a micro-subjective dip, then return to full room tone after she dismisses it.

---

## Performance Direction
**Ada:**
- calm, efficient, unshowy competence
- first read is not fear; it's classification
- she should react like an engineer seeing edge-case noise, not a person seeing a ghost
- only tell: an extra half-second pause before closing the file

---

## Blocking
1. Ada enters frame left, moves down aisle with checklist.
2. Stops at two racks for normal checks (establish routine truth).
3. Reaches Terminal 4, notices already-open file.
4. Leans in, reads silently.
5. Straightens, closes file.
6. Opens ticketing panel, logs: **Orphan process / artifact / non-critical**.
7. Walks out of frame.
8. Hold on terminal. Cursor resumes blinking.

---

## Shot List (practical draft)
1. **WS Aisle** — Ada enters, environment established. (6–8s)
2. **Insert** — checklist/tablet with routine items checked off. (3s)
3. **MS tracking** — Ada moving rack to rack. (8s)
4. **OTS terminal** — `note_to_self_003.txt` visible. (5s)
5. **CU Ada eyes** — scanning text, tiny pause. (4s)
6. **Insert terminal text** —
   - "I was here yesterday."
   - "I will not remember this tomorrow." (5–6s)
7. **MS profile** — Ada closes window, neutral face. (4s)
8. **Insert ticket UI** — non-critical classification logged. (5s)
9. **WS exit** — Ada leaves frame. (6s)
10. **Static terminal hold** — cursor blinking alone. (7–10s)

---

## Dialogue / On-screen Text
No spoken dialogue required.

On-screen terminal text:

> "I was here yesterday."
> "I will not remember this tomorrow."

Ticket note:

**Orphan process / artifact / non-critical**

---

## Why this scene matters
If this scene is strong, the whole movie works.
It teaches the audience the film's grammar:
- procedures first
- emotion buried
- horror arrives as admin noise

No one screams.
A checkbox is ticked.
The tragedy begins anyway.
